# GrandNexus — module review and auditions

Generated by `tools/module_inventory.py` (offline, 0 API call; logbook 72). The 62 experimental modules with code (83 tagged experimental, 21 of them empty package files), sorted by their path to the verdict:
- **direct**: can change a step of the core pathway (text -> premises -> program -> engine -> verdict); auditionable on FOLIO.
- **over time**: only makes sense across several sessions (memories, learning, graph); for a future "living" bench.
- **agent**: agent infrastructure; no verdict to change; only its lifecycle is checked.

An audition = one hypothesis on what the module changes on the way to the verdict, a cheap test, trivial controls, criteria written in LOGBOOK.md before measuring. Pass: candidate for wiring. Fail: stays experimental.
